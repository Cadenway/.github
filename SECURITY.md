# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

Report the issue privately in the affected repository using **Security → Report a vulnerability**, when available. If private reporting is unavailable or you are unsure which repository is affected, contact a Cadenway organization owner privately.

Please include the affected component and version or commit, the potential impact and conditions, and steps to reproduce or a proof of concept. Do not include secrets or personal data unless necessary to explain the issue.

Maintainers will review the report and coordinate any remediation and disclosure with you. Repository-specific security policies take precedence when present.
