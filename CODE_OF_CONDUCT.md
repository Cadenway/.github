# Code of conduct

Cadenway is built by people who should feel safe and respected while working together. This code applies to participation in Cadenway repositories and when representing the project.

## Expected behavior

- Be respectful and considerate, including when you disagree.
- Review the work, not the person, and explain your feedback.
- Welcome questions, give credit, and help others participate.
- Respect privacy and accept constructive feedback.

## Unacceptable behavior

Harassment, discrimination, threats, unwelcome attention, sharing private information without permission, and deliberately disrupting others' work are not acceptable.

## Reporting and enforcement

Report concerns privately to an owner of the Cadenway GitHub organization. If an owner is involved, contact another owner. Organization owners will review reports and decide on an appropriate response, which may include warnings, removal of content, or limits on participation.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
