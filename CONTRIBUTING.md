# Contributing to Cadenway

Thank you for your interest in Cadenway. Each repository owns its setup, checks, and contribution process. If a repository has its own contribution guide, follow that guide.

## Before starting

- Read the repository README and search existing issues and pull requests for related work.
- Discuss significant changes in an issue before investing in implementation.
- Follow the repository's instructions for setup, checks, and any task references.
- Never commit credentials, private keys, or other secrets.

## Proposing a change

1. Create a focused branch from the repository's default branch.
2. Keep the change scoped, add appropriate tests, and run the relevant checks documented by the repository.
3. Open a pull request describing the problem, the change, and the checks you ran. Link the related issue or task when available.
4. Address review feedback and follow the repository's review and merge requirements.

For changes spanning repositories, coordinate contracts and published packages before producers, gateways and consumers. See the relevant repository documentation for details.

For security vulnerabilities, follow the [security policy](https://github.com/Cadenway/.github/security/policy) instead of opening a public issue. All participants are expected to follow the [code of conduct](https://github.com/Cadenway/.github/blob/main/CODE_OF_CONDUCT.md).
