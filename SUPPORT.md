# Getting help

- **Setup and usage:** start with the affected repository's README and documentation.
- **Bugs and feature requests:** search existing issues, then open an issue in the repository responsible for the problem or feature.
- **Security vulnerabilities:** report them privately as described in the [security policy](https://github.com/Cadenway/.github/security/policy); do not open a public issue.
- **Contributions:** read the repository's contribution guide, or the [organization's default guide](https://github.com/Cadenway/.github/blob/main/CONTRIBUTING.md).
- **Conduct concerns:** contact an organization owner privately as described in the [code of conduct](https://github.com/Cadenway/.github/blob/main/CODE_OF_CONDUCT.md).

If you are unsure which repository to use, explore the [organization profile](https://github.com/Cadenway) for a map of the project.
